# 素材整理成教程

**把聊天、转写与截图按原话、原图、原顺序整理成可复核的教程。**

> **定位**：一个面向原始素材整理的 Agent Skill，默认把结构化结果写入钉钉 AI 文档。<br>
> **不做什么**：不把素材重写成通用方法论，不删改原话，也不伪造缺失图片。

## 为什么需要它

聊天记录和录音转写常包含完整的经验过程，但自由改写容易改变原意。本 Skill 将素材的叙事顺序保留下来，只负责分段、排版和让图片对应文字，便于用户核对和复用。

## 快速开始

```bash
git clone https://github.com/OWENWANG-GULIAI/chat-to-tutorial.git
```

将仓库中的 `SKILL.md` 安装或提供给支持 Agent Skills 的运行环境，然后提供已授权的聊天记录、转写或截图。

### 调用示例

```text
使用 $chat-to-tutorial，把这份聊天记录按原话、原图和原顺序整理成教程；默认写入钉钉 AI 文档。
```

预期输出：一份含标题、简短导语、原话分段、原图及图说的教程；同时保留本地 Markdown 源稿。

## 工作原理

1. 识别聊天 zip、文本、转写或截图，并确认图片是否随素材提供。
2. 依照原始叙事顺序生成 Markdown，原话用引用块保留。
3. 仅在用户授权且环境支持时，创建钉钉 AI 文档并按图说位置插图。
4. 交付文档链接和本地源稿，并提示用户核对图文对应关系。

## 核心能力

- 保留原话、原图和原始叙事顺序，不将素材改写为通用方法论。
- 检查 zip 是否实际包含图片；缺图时明确标记待补，不伪造图片或图说。
- 生成可复核的 Markdown 源稿，并在用户授权且环境支持时写入钉钉 AI 文档。

## 适用与不适用

适用于将真实聊天、客户原话、录音转写和截图沉淀为教程或笔记。不适用于没有原始素材的自由写作，也不适用于仅要摘要、翻译或润色的请求。

## 适用场景

- 将已授权的微信或钉钉聊天记录整理为可核对的教学文档。
- 为录音转写、客户原话或操作截图制作保留叙事顺序的笔记。
- 在用户明确要求时，输出带原图和图说的钉钉 AI 文档。

## 输入与输出

| 类型 | 内容 |
|---|---|
| 输入 | 已授权的聊天 zip、Markdown、文本、转写或截图；可选标题和目标平台 |
| 输出 | 本地 Markdown 源稿；默认情况下为钉钉 AI 文档及其图文内容 |

## 仓库结构

- [`SKILL.md`](SKILL.md)：入口、执行流程、外部写入边界与验收标准。

## 隐私与边界

- 只处理用户提供或明确授权的素材。
- 原始素材可能含个人信息；公开示例和仓库不应包含真实聊天、截图或客户数据。
- 创建文档、上传图片和任何外部写入均需要用户明确授权。

## 当前版本边界

- 默认写入钉钉 AI 文档的流程依赖运行环境提供并已授权的 `dws` 命令；缺失时只能输出本地 Markdown 或改用用户指定的平台。
- 输入 zip 未附带图片时，只能写明待补位置，不能生成或杜撰图片。
